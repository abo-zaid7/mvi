TASK 1 - CLASSICAL VESSEL SEGMENTATION
Files for the GUI: results + how to run
=======================================

WHAT THIS IS
A semi-automated retinal vessel segmentation method. No deep learning; runs on
CPU. Input: a colour fundus photograph. Output: a binary vessel mask.

FILES
  results/                results for display (see below)
  fives_pipeline.py       the pipeline (segmentation + the two operator controls)
  operating_point.json    the tuned parameters the pipeline runs with

RESULTS FOR DISPLAY
  results/images/   ALL 200 test images (the FIVES test split). For every image:
      <name>_input.png        input image (colour fundus photo, 512x512)
      <name>_gt.png           ground truth mask   (white = vessel, 512x512)
      <name>_prediction.png   our segmentation    (white = vessel, 512x512)
    The four report cases (13_A, 54_D, 114_G, 57_D) additionally have:
      <case>_overlay.png      prediction drawn over the image:
                              red  = vessel found that is not in the ground truth
                              blue = ground-truth vessel that was missed
  results/metrics_per_image.csv   per-image numbers for all 200 images:
                                  dice, iou, accuracy, hd95_px, precision, recall, cldice
                                  (the project's recorded evaluation - use these, not a
                                  recompute from the 512px display copies)
  results/metrics_cases.csv       the same numbers for the four report cases
  results/metrics_summary.csv     averages over the full 200-image test set
