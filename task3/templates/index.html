    How to use this

    Walkthrough

    1. Pick a model on the left and press Load. A three-note chime means it is in memory, and its size, parameter count and FLOPs appear underneath.
    2. Choose a scan. The default list is the 200 scans Task 2 was scored on, so the numbers you see match the report.
    3. For a Task 1 model, drag a rough box round the lesion, or press Simulate box to use the same loose box the evaluation used. Task 2 models need no box.
    4. Press Segment. The outlines appear on the scan and the scores appear on the right.

    Reading the metrics

    Keyboard

    • R Run the model
    • B Simulate the box
    • N / P Next / previous scan
    • 1–6 Switch view
    • M Mute or unmute
    • ? This window
    • Esc Close a window

    If something goes wrong

    The Task 1 model will not load
    The forest runs in a separate helper process using mvi-env. Check that the mvi-env folder is still next to task3, then press Load again — that restarts the helper.
    No scans are listed
    The BRISC 2025 folder has to sit beside task3 as brisc2025/segmentation_task. Uploading your own scan works without it.
    Metrics show a dash
    That scan has no ground truth mask, so there is nothing to score against. The segmentation is still shown.
    There is no sound
    Browsers block audio until the page has been clicked once. Click anywhere, and check the speaker button in the header is on.
